# CareerKit — Resume Builder

React resume builder with a local template-based summary generator. No API key or backend server is required.

## Run locally
1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).

The summary helper uses JavaScript templates, not a live AI model. Review the generated text for accuracy.
